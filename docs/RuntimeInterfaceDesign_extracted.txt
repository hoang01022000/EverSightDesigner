Chapter 9 Build a Solution: Design the Run-time
Interface
The Run-time Interface is for intuitive control and monitoring of the solution in the running
status. With the Run-time Interface, the end users, i.e., the operators at the manufacturing
site, can view the inspection results in real time and determine whether to stop running the
solution—even the corresponding assembly line at large—in particular cases. This section
introduces the features of the Run-time Interface Design window and how to customize
the interface to suit specific  requirements.

9.2 Design the Run-time Interface
You can design the Run-time Interface based on the business requirements to help the end
users monitor and control the solution execution easily and more intuitively, thus
improving their work efficiency.
9.2.1 General Design Approach
By default, the Run-time Interface is empty, and you need to customize it in the Run-time
Interface Design  window as needed.
The overall design approach is:
1. Use a template or not: in the Run-time Interface Design  window, click 
  to check if the
template satisfies  your requirements. If yes, you can select it and modify the design as
needed; if not, proceed to the next step.
2. Set fixed  column layout: click 
  to set the required fixed  column at the top/bottom/left/
right side of the Run-time Interface.
3. Set the layout: select the canvas and set the overall layout in the attribute setting area.
4. Add and configure  widgets: click and drag required widgets into the fixed  columns or
the canvas, and configure  the input source and other settings.
Note
When setting a widget, you can set its position, and alignment with controls in the
toolbar.Vision Master Platform User Manual

9.2.2 Basic Operations on Widgets
The basic functional unit in an operation window is the widget. To design a well-
functioning window, add multiple widgets and configure  their parameters.
In the Widget Area, click and drag a required widget, move it into the Preview and Edit Area,
and drop. Once added, you modify its position and size as needed and configure  the Data
Source and other settings in the Attribute Setting Area.

Displays information after you subscribe to a data source, and allows you to

Format String
This parameter is automatically loaded after you set the Data Source  and is
displayed as "Description for subscribed data: <subscribed data>" by default. You
can customize the "Description for subscribed data:".
"<subscribed data>" is a formatted syntax, which varies in different data types.
○When you set Data Type  to string , the formatted syntax is "%s".
○When you set Data Type  to int, the formatted syntax is "%0d".
›If the formatted syntax remains at its default content, the widget will output
the int-type data of the data source.
›If you have special needs, you can modify the Arabic numeral after "%" to set
the maximum number of digits for the output int-type data. For example, if the
original data is 600, and the formatted syntax is set to "%5d", then the widget
will output 00600 when the solution is executed.
○When you set Data Type  to float , the formatted syntax is "%1.3f". In this case,
three effective numbers are remained behind the decimal point. You can
customize the arabic numeral after "%". For example, "%1.6f" represents that six
effective numbers are remained behind the decimal point.
Note
Ensure that you know the requirements related to formatted syntaxes when setting
this parameter. If not, contact our technical support for more information.
